# Bab 9 — Laporan Keuangan

[← Akuntansi](08-akuntansi.md) · [Daftar Isi](README.md) · [Lanjut: Sistem →](10-sistem.md)

---

Menu **Akuntansi → Laporan**. Semua laporan bisa filter periode, cetak (PDF), dan export Excel.

## 9.1 Neraca (Balance Sheet)
Posisi keuangan pada tanggal tertentu: **Aset = Kewajiban + Ekuitas**.
- Verifikasi sistem sehat: kalau tidak balance, ada masalah posting.
- Lihat nilai persediaan, kas, piutang, hutang, aset tetap, modal.

## 9.2 Laba Rugi (Profit & Loss)
Kinerja periode: Pendapatan − HPP − Beban = Laba/Rugi.
- Pendapatan penjualan, HPP (modal barang terjual), beban operasional.
- Bandingkan antar periode untuk tren.

## 9.3 Arus Kas (Cash Flow)
Uang masuk/keluar dikelompokkan: Operasi, Investasi, Pendanaan.
- Lihat dari mana kas datang & kemana perginya.

## 9.4 Trial Balance (Neraca Saldo)
Daftar semua akun + saldo debit/kredit. Total debit harus = total kredit.
- Alat cek cepat keseimbangan pembukuan.

## 9.5 Aging Piutang / Hutang (AR/AP Aging)
Umur piutang & hutang dikelompokkan (0-30, 31-60, 61-90, >90 hari).
- Tahu siapa nunggak, mana yang jatuh tempo.
- Untuk piutang: prioritas penagihan. Untuk hutang: rencana bayar.

## 9.6 Buku Besar per Akun (Ledger Book / Ledger Detail)
Mutasi detail per akun dalam periode: saldo awal → transaksi → saldo akhir.
- Pilih akun (mis. 1.2.2 Piutang Karyawan) → lihat semua mutasi + running balance.
- Berguna untuk telusuri saldo akun tertentu.

## 9.7 Profitabilitas per SKU
Laporan khas: margin per produk.
- **Material margin** (harga jual − harga modal WAC) vs **Loaded margin** (− HPP loaded termasuk biaya produksi).
- Coverage % (berapa % penjualan yang ter-track batch).
- Tahu produk mana paling untung (loaded, bukan cuma material).

## 9.8 Laporan Lain
- **Dashboard** (halaman depan): KPI real-time — kas, piutang, hutang, laba MTD, nilai persediaan, produksi, aset, widget peringatan (DO belum invoice, stok minus, penyusutan due).
- Export semua laporan ke Excel untuk olah lanjут / lapor pajak.

---

## Contoh Kasus: Cek Kesehatan Bulanan
Akhir bulan, owner mau review:
1. **Neraca** → pastikan balance, lihat posisi kas & persediaan.
2. **Laba Rugi** bulan ini vs bulan lalu → tren laba.
3. **Aging Piutang** → daftar customer nunggak → tindak lanjut tagih.
4. **Profitabilitas per SKU** → produk mana margin tipis → evaluasi harga.
5. **Dashboard** → cek widget peringatan (DO pending, stok minus).
