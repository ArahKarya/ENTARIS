# Entaris × AIRA — Brand Kit

Logo resmi **Entaris** (ERP, *Agentic Reasoning System*) dan agen AI-nya, **AIRA** (*AI Reasoning Agent*). Keduanya produk **PT Arah Karya Sinergi** dan dirancang sebagai satu keluarga:

| | Entaris | AIRA |
|---|---|---|
| Logo | "Anyaman ∇" (segitiga terbalik) | "Lipat Δ" (∇ yang dibalik, terbaca sebagai A) |
| Makna | ∇ gradien: sistem yang **bernalar** | Δ perubahan: agen yang **bertindak** |
| Aksen wordmark | **TA** biru | **AI** biru |

Baca **`Panduan-Merek-Entaris-AIRA.pdf`** untuk panduan lengkap yang siap dibagikan ke tim, desainer, atau mitra.

Keduanya memakai grid yang sama (kanvas 512, segitiga sisi 440, bilah 88), palet yang sama, dan tipografi yang sama (Archivo ExtraBold Extended untuk wordmark, Archivo Medium untuk tagline).

## Cara pakai singkat
- Latar terang: pakai file **tanpa akhiran**. Latar navy atau gelap: pakai **`-negative`**. Cetak satu warna, stempel, atau emboss: pakai **`-mono`**.
- Untuk web dan dokumen, pilih **SVG** karena tajam di semua ukuran. **PNG** transparan untuk Office, Canva, dan aplikasi chat.
- Di bawah lebar ±120 px, pakai simbol atau ikon saja, tanpa wordmark.
- Jangan memutar, meregangkan, atau mengubah warna simbol. Aturan lengkapnya ada di README masing-masing.
